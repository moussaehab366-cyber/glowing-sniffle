# Yasmin Mohamed — Portfolio

A responsive personal portfolio built with HTML and CSS.

## Run locally
1. Download and extract the project ZIP.
2. Open `index.html` in your browser.
3. Optional: open the folder in VS Code and use Live Server.

## Before publishing
- Replace the sample email address.
- Replace the GitHub username and LinkedIn placeholder.
- Add real projects and links.
- Confirm all listed skills match your experience.

## Technologies
- HTML5
- CSS3
- Responsive layout with CSS Grid and Flexbox
